# 해원대학교 가상 공식 홈페이지

작품 《해원대학교 특수학부》를 위한 가상 대학교 웹사이트입니다. 실제 교육기관과 무관합니다.

## 로컬에서 보기
`index.html`을 브라우저로 열면 됩니다. HTML/CSS/JS로 제작되어 별도 설치나 빌드가 필요 없습니다.

## Vercel 배포
1. Vercel에 로그인합니다.
2. 이 폴더를 GitHub 저장소에 올립니다.
3. Vercel에서 Add New > Project를 선택하고 해당 저장소를 Import합니다.
4. Framework Preset은 Other, Build Command는 비워두고 Deploy를 누릅니다.
5. 배포된 주소를 작품 소개에 추가합니다.

## 기능
- 모바일 대응 메뉴 및 페이지 이동
- 학부/용어 소개
- 학생회 인물 상세 팝업
- 캠퍼스 개념도 및 장소 선택
- 공지사항 검색 및 상세 보기
- 로컬에서만 생성되는 가상 학생증

## 수정하기
공지 내용, 인물 프로필, 캠퍼스 장소 정보는 `app.js` 상단의 데이터 배열에서 수정할 수 있습니다.
메인 이미지와 인물 이미지는 `assets` 폴더에 있습니다.
