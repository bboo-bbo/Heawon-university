# 해원대학교 공식 홈페이지 v2

가상의 해원대학교 특수학부를 위한 정적 웹사이트입니다.

## 배포 방법
GitHub 저장소 **최상위 경로**에 `index.html`, `style.css`, `app.js`, `vercel.json`, `assets/` 폴더를 올려주세요. ZIP 파일 자체를 GitHub에 올리면 웹사이트가 갱신되지 않습니다.

기존 Vercel 프로젝트가 GitHub 저장소에 연결되어 있다면, GitHub의 `main` 브랜치에 변경 사항을 커밋한 뒤 자동 재배포됩니다.

## 이미지
- 캠퍼스 사진 10장: 사용자가 제공한 원본 사진을 내용 변경 없이 웹용 JPEG로 변환
- 학생회 증명사진: 차이헌, 류시안, 도건우의 확정 이미지를 사용
- 서유라 미포함

## 기능
상단 메뉴, 학생회 프로필, 캠퍼스 사진별 상세 보기 및 분류, 공지사항 검색, 가상 학생증.

이 사이트는 실제 교육기관과 무관한 창작물입니다.
